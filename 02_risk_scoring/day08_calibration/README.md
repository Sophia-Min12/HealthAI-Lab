# Day 8 · Calibration: A 30% Risk That Is Right 30% of the Time

> **NOT A MEDICAL DEVICE.** Every patient in this repo is generated by it.

Day 6 found that AUC does not move with prevalence. This is the harder half of the same fact: **AUC does not move with calibration either.**

## Does 30% mean 30%?

```
  predicted risk  patients   promised   happened      gap
         0%-10%     21918      0.055      0.055   -0.000
        10%-20%     11666      0.140      0.139    0.002
        20%-30%      3921      0.242      0.245   -0.003
        30%-40%      1574      0.342      0.346   -0.004
        40%-50%       596      0.442      0.455   -0.013
        50%-60%       220      0.538      0.523    0.015
        60%-70%        83      0.640      0.675   -0.034
        70%-80%        18      0.742      0.556    0.187
        80%-90%         4      0.819      0.500    0.319
```

ECE 0.0014. The model is very well calibrated — and it should be: Day 5 generated this cohort *from* a logistic model and fits a logistic model, so the family is exactly right. That is a property of the experiment rather than an achievement.

The last two bins are off by 0.19 and 0.32, on eighteen patients and four. A reliability diagram is a set of small samples in its tails, and those bins say nothing.

## Calibration and discrimination are independent

Distort the probabilities while preserving their **order**. Any monotone transform leaves the ranking alone, so AUC cannot move by construction:

```
distortion                       AUC      ECE    Brier
none                          0.7353   0.0014   0.0955
over-confident, odds^1.6      0.7353   0.0634   0.1002
under-confident, odds^0.5     0.7353   0.1312   0.1134
shifted up, odds x 3          0.7353   0.1447   0.1211
shifted down, odds x 1/3      0.7353   0.0730   0.1037
```

**The AUC column is one number repeated five times, to four decimal places**, while the calibration error moves by a factor of a hundred.

So a paper reporting AUC 0.74 has said nothing about whether its 30% means 30%. The two are not loosely related — AUC is a function of the *order* of the predictions and calibration is a function of their *values*.

## Which is why the Brier score is the more honest number

```
Brier = reliability − resolution + uncertainty

                  reliability  resolution  uncertainty    Brier
original              0.00003     0.00923      0.10530  0.09611
distorted             0.00221     0.00919      0.10530  0.09832
repaired              0.00003     0.00924      0.10530  0.09610
```

The distortion moved reliability **seventy-fold** and left resolution and uncertainty where they were. Resolution is discrimination — the thing AUC measures — and uncertainty belongs to the base rate, which no model can change.

That is the decomposition earning its place: it separates the part a monotone transform can ruin from the part it cannot.

## Repairing it costs nothing that matters

```
                        AUC      ECE    Brier
original             0.7353   0.0014   0.0955
distorted            0.7353   0.0323   0.0977
Platt-repaired       0.7353   0.0014   0.0955
```

Platt scaling fits `sigmoid(a · logit(p) + b)`. It is monotone, so it cannot change the ranking or the AUC — which is exactly why it is a calibration fix and not a new model.

## Why this matters more than the rest of Level 2

Day 7 chose a threshold from a cost ratio, and that arithmetic assumes the predicted probability *is* a probability. The 5:1 cut is 0.167 in every row below; only the scores differ:

```
scores                         ECE    sens  flagged  workload
well calibrated              0.001   50.5%     8864     1.00x
odds^1.6 x 2.5               0.032   49.0%     8494     0.96x
odds x 3                     0.145   88.5%    26653     3.01x
odds x 1/3                   0.073   11.8%     1190     0.13x
odds^0.4                     0.172   99.7%    38981     4.40x
```

Same threshold, same cost belief, same patients, same ranking, **same AUC to four decimals** — and a clinic seeing between a seventh and four and a half times as many people.

Note the second row. That distortion has an ECE of 0.032 and changes the workload by 4%: some miscalibrations happen to be nearly harmless at a particular threshold. Nothing in the AUC, and nothing in the ECE alone, says which kind you have — it depends on where the distortion bites relative to your cut. Both directions are pinned by tests.

**A miscalibrated model does not merely report the wrong number to the patient. It silently invalidates every decision rule built on top of it, by an amount nobody can predict from the summary statistics.**
